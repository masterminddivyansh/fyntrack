# FynTrack

Premium finance calculators and planning tools built with React + Vite.

## Included
- Premium responsive homepage / landing page
- Calculator mega-menu in the header
- Calculator workspace with persistent sidebar
- Smart calculator, FD, RD, SIP, Lumpsum, PPF, NPS, EMI, Inflation, Petrol Cost, Salary and GST calculators
- Years + months duration controls where applicable
- Dark / light mode with persistence
- Non-functional login/create-account placeholder
- About, Contact, Privacy Policy, Terms of Use and Disclaimer pages
- GitHub Pages deployment workflow
- GitHub Pages-compatible hash navigation

## Local
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## GitHub Pages
The Vite base is `/fyntrack/` for the repository deployment. The included workflow deploys `dist` automatically on pushes to `main`.


## Calculator strategy
FynTrack intentionally focuses on a restricted set of high-intent finance calculators rather than publishing dozens of low-use tools. The current hub prioritizes SIP, lumpsum, SWP, mutual-fund returns, CAGR, compound interest, FD, RD, PPF, NPS, retirement, EMI, loan eligibility, income tax, salary, GST, gratuity, EPF, inflation and petrol cost.
